ROLE:
Act as a senior Django full-stack developer. Implement a Bill system that supports both:

1. Automatic creation from Purchase Order
2. Manual bill creation

---

SYSTEM CONTEXT:

* Django Inventory Management System
* Existing models:

  * Vendor
  * Product
  * PurchaseOrder
  * PurchaseOrderItem

---

## CORE REQUIREMENT

System must support TWO ways to create Bills:

### A. From Purchase Order (AUTO)

### B. Manual (FROM SCRATCH)

---

## 1. BILL MODEL

Bill:

* id
* vendor (FK)
* purchase_order (FK, null=True, blank=True)
* bill_date
* total_amount
* status (unpaid/paid)

BillItem:

* bill (FK)
* product (FK)
* quantity
* cost_price
* total_price

---

## 2. OPTION A: CREATE BILL FROM PURCHASE ORDER

### UI:

* Button on Purchase Order page:
  "Create Bill"

---

### LOGIC:

When clicked:

1. Fetch PurchaseOrder using slug

2. Create Bill:

   * vendor = purchase_order.vendor
   * purchase_order = selected order
   * total_amount = calculated

3. Loop through PurchaseOrderItems:
   → create BillItems:
   - product
   - quantity
   - cost_price = price_per_item
   - total_price

---

### RESULT:

* Fully auto-filled bill
* No manual input needed

---

## 3. OPTION B: MANUAL BILL CREATION

### UI:

* Separate page:
  "Create Bill"

---

### FORM:

* Select Vendor
* Add multiple products (dynamic rows)
* Enter:

  * quantity
  * cost price

---

### LOGIC:

* Create Bill without PurchaseOrder:
  purchase_order = NULL

* Create BillItems from form input

---

## 4. AUTO-FILL BEHAVIOR (IMPORTANT)

If Bill is created FROM Purchase Order:

* Fields must be pre-filled
* Items must be copied automatically

If created manually:

* No auto-fill
* User inputs everything

---

## 5. VALIDATION

* Bill must have vendor
* Must have at least one item
* Prevent empty bill creation

---

## 6. OPTIONAL SAFETY

* Prevent duplicate bills for same PurchaseOrder
* OR show warning if bill already exists

---

## 7. UI STRUCTURE

Sidebar:

* Purchases
  → Vendors
  → Purchase Orders
  → Bills

Bills Page:

* Button:
  "Create Bill"
* Table listing bills

---

## 8. CONSTRAINTS

* DO NOT mix auto and manual logic in same form
* DO NOT duplicate product data incorrectly
* Keep relationships clean:
  PurchaseOrder → Bill → BillItems

---

## 9. OUTPUT FORMAT

Provide:

1. models.py (Bill, BillItem)
2. views.py (auto + manual creation)
3. urls.py
4. templates (form + list + detail)
5. short explanation

---

## EXPECTED RESULT

* User can create Bill from Purchase Order (auto-filled)
* User can create Bill manually
* Bills correctly store vendor, products, quantity, price
* Clean and flexible workflow similar to real systems
